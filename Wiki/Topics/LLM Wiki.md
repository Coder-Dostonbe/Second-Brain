# LLM Wiki

## Overview

An LLM Wiki is a knowledge base structured for AI agents: it keeps captured [[Raw Source Vs Wiki Note|raw source material]] separate from compiled, reusable knowledge notes, so an agent can search the compiled layer first and only fall back to raw material when it needs more evidence.
