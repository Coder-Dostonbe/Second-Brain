# EduFlow CRM

## Goal

O'quv markazlari uchun premium CRM. Haqiqiy o'zbek o'quv markazi asosida
qurilgan: o'quvchilar, guruhlar, jadval, davomat, imtihonlar, moliya va lead
pipeline. Interfeys o'zbek, rus va ingliz tillarida.

## Status

- Full stack: Next.js (App Router) frontend + Django 5 / DRF backend,
  `docker-compose.yml` bor.
- `npm run dev` bitta buyruq bilan API va frontendni ko'taradi, migratsiya va
  demo data seed qiladi. `DATABASE_URL` bo'lmasa SQLite'ga tushadi.
- Google OAuth va rolga qarab cheklangan o'quvchi kabineti qilingan.
- Repo: GitHub `Coder-Dostonbe/EduCrm`. Oxirgi lokal o'zgarish: 2026-10-07.
- Repoda `AGENTS.md`, `CLAUDE.md`, `WORKFLOW.md` bor.
