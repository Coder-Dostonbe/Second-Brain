# Fezot Shop

## Goal

"fezot" kiyim brendi uchun Django e-commerce do'kon, uch tilli (uz/ru/en).

## Status

- Bitta app'li Django loyiha: paket `core`, domen logikasi `shop` app'ida.
- Django 6.0.2, SQLite, django-allauth, django-widget-tweaks.
- API qatlami yo'q: sahifalar server-side template, faqat AJAX
  cart/wishlist/filter endpointlari JSON qaytaradi.
- Model tarjimalari qo'lda qilingan (`modeltranslation` registratsiyasisiz).
- Ish multi-agent koordinatsiya bilan yuritiladi:
  [[Multi-Agent Claude Code Coordination]].
- Oxirgi lokal o'zgarish: 2026-10-10. Papkada git repo yo'q.
